   118→// ─── Print helpers ────────────────────────────────────────────────────────
   119→// We render the receipt into a freshly-opened popup window using a fully-
   120→// formed HTML string. This avoids the previous in-page hidden-DOM approach,
   121→// which was racy: the browser sometimes printed before React had mounted
   122→// the receipt subtree (blank page) or printed only the header on reprint
   123→// because the receipt body had been removed during an earlier cleanup.

   125→// Doing all the work in a self-contained HTML string also means the same
   126→// template is used for fresh prints (?print=1) and reprints, and we don't
   127→// depend on the `clinic` query already being warm in the cache.
